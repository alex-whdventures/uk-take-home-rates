# UK Take-Home: tax rates

Public tax rates used by the UK Take-Home app. The app bundles these files and refreshes them from here at launch, so rate changes reach every user without an App Store update.

- One file per tax year: `2026-27.json` etc. `index.json` lists the years and their status (`confirmed`, `provisional`, `projection`).
- Figures come from GOV.UK, gov.scot and HMRC. They are published here exactly as tested in the app's engine.
- Do not edit these files by hand. They are generated by the app repository (`npm run rates:export`) after the engine's tests pass.

Information only; not tax or financial advice.
